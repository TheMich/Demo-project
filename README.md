# "No fighting in the Gun Museum": A Unity tutorial project

This project is based on the excellent [tutorial by Tom Francis](https://www.youtube.com/playlist?list=PLUtKzyIe0aB3TZfe2wsIgJgGZW5G_NAxa) (credit for the working title goes to him as well). 

## Notes

Work in progress. Press 'e' to collect useable items in each level.
